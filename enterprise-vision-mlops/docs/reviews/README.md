# Phase Review Documents

This directory stores final review documents created when a major schedule block
such as W0, W1, W2, or W3 is closed.

Each review should summarize:

- original objective and scope
- completed Jira/GitHub work items
- implemented architecture and key design decisions
- validation commands and runtime evidence
- issues found, root causes, and resolutions
- remaining technical debt
- handoff items for the next schedule block
- portfolio-ready technical narrative
